# Codex Skills

Personal Codex skills managed as source code.

## Skills

- `backend-learning-project`: create compact backend learning projects for any language/framework and generate code-reading guides.

## Layout

```text
skills/
  backend-learning-project/
    SKILL.md
    references/
```

To install a skill locally, copy or symlink the skill directory into your Codex skills directory, usually `~/.codex/skills/`.
